# 👋 DropMD へようこそ

DropMD は Mac 用の Markdown エディタです。**Word のように見たまま書式を付けて**、保存すると標準の Markdown ファイルになります。Word、Excel、PowerPoint、PDF などのファイルを Markdown に変換することもできます。

> [!TIP]
> このガイド自体が Markdown の書類です。自由にクリックしたり書き換えたりして、機能を試してみてください。壊れる心配はありません。メニュー「ヘルプ → DropMD ユーザーガイド」から開くたびに、新しいコピーが開きます。

## 🚀 3 ステップで始める

- [ ] メニュー「ファイル → 新規」（⌘N）で新しい書類を作る
- [ ] 1 行目の先頭に `# ` と入力してから文字を打つと、大見出しになります。改行したらそのまま本文を書きます
- [ ] 文字を選択して ⌘B で太字に。書き終えてウインドウを閉じるときに保存場所を選ぶと、`.md` ファイルができます

> [!NOTE]
> Markdown の書き方を知らなくても大丈夫です。画面に見えているのがそのまま仕上がりで、保存するときに自動で Markdown として書き出されます。

## ✍️ 書く

### ページと分割

ツールバーのいちばん左で、2 つの表示を切り替えられます。

| 表示 | ショートカット | 向いている使い方 |
| --- | --- | --- |
| **ページ** | ⌘1 | Word や Pages のように見たまま書く |
| **分割** | ⌘2 | 左が Markdown の原文、右がページ表示。どちらでも編集でき、内容とスクロールが常に連動します |

分割表示で左のカーソルを動かすと、右側に対応する位置が表示されます。オフにしたり、マーカーのスタイル（枠線、サイドバー、カーソル）を変えたりするには「DropMD → 設定… → 一般」を開きます。中央の区切り線はドラッグで幅を変えられ、ダブルクリックで半分ずつに戻ります。

### 入力しながら自動で書式を付ける

段落の先頭で次の記号を入力し、スペースを押します。

| 入力 | 結果 |
| --- | --- |
| `# ` `## ` `### ` | 見出し 1、2、3 |
| `- ` または `* ` | 箇条書き |
| `1. ` | 番号付きリスト |
| `[] ` | チェックリスト（四角をクリックでチェック） |
| `> ` | 引用 |

### よく使うショートカット

| 操作 | ショートカット |
| --- | --- |
| 太字 / 斜体 / 下線 | ⌘B / ⌘I / ⌘U |
| 取り消し線 / ハイライト | ⇧⌘X / ⇧⌘H |
| インラインコード | ⌥⌘C |
| 見出し 1〜6 / 本文 | ⌥⌘1〜⌥⌘6 / ⌥⌘0 |
| リンク / 画像 | ⌘K / ⇧⌘K |
| 表 | ⌥⌘T |
| インデントを増やす / 減らす | Tab / ⇧Tab（リスト内） |
| 段落を分けずに改行 | ⇧↩ |
| フォーマットパネルを表示 | ⌥⌘I |

すべてのコマンドは「フォーマット」メニューと「挿入」メニューにもあります。右側のフォーマットパネルにはカーソル位置の書式が表示され、クリックするだけで変更できます。

### 右クリックメニュー

右クリックした場所に合わせて、よく使う操作が表示されます。

- **表**：行・列の挿入と削除、配置、表をコピー、表を削除
- **リンク**：開く、編集、コピー、削除
- **画像**：代替テキストを編集、Finder に表示、画像を削除
- **コードブロック**：コードをコピー、言語を選ぶ
- **コールアウト**：種類を変える、引用に変換
- **選択した文字**：取り消し線、ハイライト、インラインコード、書式をクリア

## 📦 いろいろなものを挿入する

ツールバー中央のボタンか、「挿入」メニューを使います。

### 表

- Tab または Return で次のセルへ移動します。最後のセルで Tab を押すと行が増え、Return を押すと表の下に移ります
- 2 つの列の境目をドラッグすると、列の幅を変えられます
- 行全体を選択して Delete を押すと、その行を削除します。表のすぐ下の段落の先頭で Delete を 2 回押すと、表全体を削除します（1 回目は選択するだけなので、うっかり消えません）

### コールアウト

今見ているような色付きの枠がコールアウトです。「注」「ヒント」「重要」「警告」「注意」の 5 種類があります。

> [!IMPORTANT]
> コールアウトは GitHub や Obsidian でも色付きの枠として表示されます。

### コードブロック

段落をコードブロックにしたら、右クリックメニューでプログラミング言語を選べます。コードブロックにポインタを乗せると、右上にコピーボタンが表示されます。

```swift
print("Hello, DropMD!")
```

### 折りたたみセクション

<details>
<summary>ここをクリックして開く</summary>

折りたたみセクションは、中身を隠しておけます。タイトルの前の三角をクリックすると開いたり閉じたりします。挿入のショートカットは ⇧⌘D です。

</details>

### 数式、脚注など

- **数式**：インライン数式 ⌥⌘M、数式ブロック ⇧⌥⌘M。LaTeX で書きます（例：$E=mc^2$）。数式をダブルクリックすると編集できます
- **脚注**：⌥⌘F でカーソル位置に番号を入れ、説明は書類の最後に自動で置かれます
- **画像**：Mac 内の画像は、できるだけ書類からの相対パスで挿入されます。プライバシー保護のため、**ネット上の画像は読み込みません**
- **今日の日付**、**絵文字と記号**：「挿入」メニューにあります

## 🔗 リンク

リンクをクリックすると、初期設定では開く前に確認します。リンクの文字を直したいだけなのに開いてしまう、ということがありません。「DropMD → 設定… → 一般 → リンクをクリックしたとき」で「すぐに開く」か「⌘ を押しながらクリックで開く」に変えられます。⌘ を押しながらクリックすると、いつでもすぐに開きます。

別の `.md` ファイルへのリンクは DropMD で開き、それ以外のファイルへのリンクは Finder で表示します。

## 📤 保存・書き出し・共有

- **自動保存**：「テキストエディット」と同じように自動で保存されます。以前の内容に戻すには「ファイル → 復元 → すべてのバージョンをブラウズ…」を使います
- **書き出す**：ツールバーの「書き出す」ボタンで **PDF**（A4）または **HTML** に書き出せます。HTML には Mac 内の画像が埋め込まれるので、ほかの人に送っても表示されます
- **共有**：ツールバーの「共有」ボタンで、AirDrop、メール、メッセージなどで `.md` ファイルを送れます
- **クイックルック**：Finder で `.md` ファイルを選んでスペースキーを押すと、開かずに仕上がりを確認できます

> [!TIP]
> ウインドウ左下で書類の言語（簡体字中国語、繁体字中国語、日本語、韓国語）を選べます。同じ漢字でも言語によって字形が違うので、正しく選ぶとその言語の字形で表示されます。

## 🔄 ファイルを Markdown に変換する

メニュー「ファイル → ファイルを Markdown に変換…」（⇧⌘T）で変換ウインドウを開きます。

1. ファイルやフォルダをウインドウにドラッグするか、「ファイルを選択…」をクリックします
2. モードを選びます
   - **高速**：Word、Excel、PowerPoint、HTML、CSV、文字を選択できる PDF 向け
   - **高精度**：論文、スキャンした PDF、表や数式を含む PDF 向け（PDF のみ）
3. 「変換を開始」をクリックします。終わったら、リストのファイルをダブルクリックすると DropMD で開きます

変換した `.md` は、初期設定では元のファイルの隣に保存され、Word の画像は「ファイル名_images」フォルダに書き出されます。**元のファイルは変更されません。**

> [!NOTE]
> 高精度モードを初めて使うときは、認識モデルのダウンロードが必要です（約 530 MB。「数式を認識」を使う場合はさらに約 640 MB）。ダウンロード元とサイズを表示し、同意したときだけダウンロードします。一度ダウンロードすれば、あとはオフラインで使えます。

| OCR エンジン（高精度モード） | 特長 |
| --- | --- |
| **RapidOCR**（初期設定） | 簡体字・繁体字・日本語・英語が混ざったページも認識できます |
| **Apple Vision** | macOS に内蔵。1 つの言語だけの書類向けで、主な言語を選びます |
| **Xiaomi-OCR-0** | より正確で、数式や表も一緒に認識します。初回に約 1.8 GB のダウンロードが必要で、時間がかかります |

## ⚙️ 設定

「DropMD → 設定…」（⌘,）は 4 つのページに分かれています。

| ページ | できること |
| --- | --- |
| **一般** | 外観（ライト / ダーク）、ページの余白、リンクをクリックしたとき、分割表示の位置マーカー、言語、`.md` ファイルのデフォルトアプリにする |
| **アップデート** | 新しいバージョンの確認、起動時の自動確認、ベータ版を含める |
| **支援** | DropMD を気に入ったら、作者にコーヒーをごちそうできます |
| **情報** | バージョン、GitHub リポジトリ、問題を報告、コミュニティ、オープンソースライセンス |

> [!TIP]
> 新しいバージョンはまずベータ版として公開されます。新機能をいち早く試したい場合は、「アップデート」ページで「ベータ版を含める」をオンにしてください。

## 🔒 プライバシー

- 編集も変換もすべてお使いの Mac の中で行われ、ファイルがアップロードされることはありません
- ネットにつながるのは 2 つだけで、どちらもあなたの同意が必要です：高精度モードの認識モデルのダウンロードと、アップデートの確認
- データ収集、利用統計、広告はなく、勝手に何かをインストールすることもありません

## ❓ よくある質問

<details>
<summary>保存したら書式が消えた？</summary>

Markdown で保存できるのは、太字、斜体、見出し、リスト、表などの書式です。フォント、文字サイズ、文字の色、配置などは保存できないので、ツールバーにもボタンがありません。Web ページや Word から貼り付けると、太字・斜体・リンクは残り、それ以外の書式は取り除かれます。

</details>

<details>
<summary>一部の内容が等幅フォントで表示される？</summary>

ページ表示がまだ対応していない書き方（一般的な HTML コード、ファイル先頭の YAML 情報など）はこのように表示され、元のまま保存されるので失われません。分割表示に切り替えると、左側で直接編集できます。

</details>

<details>
<summary>どんなファイルを変換できる？</summary>

`.docx`、`.xlsx`、`.pptx`、`.html`、`.pdf`、`.csv` です。古い Office 形式（`.doc`、`.xls`、`.ppt`）は、Office で新しい形式に保存し直してください。暗号化やパスワードのかかったファイルは変換できません。

</details>

<details>
<summary>問題はどこに報告すればいい？</summary>

「ヘルプ → 問題を報告…」で GitHub の報告ページが開きます。「ヘルプ → Discord コミュニティに参加…」からコミュニティに参加することもできます。

</details>
