# DropMD ユーザーガイド

DropMD は Mac 用の **Markdown エディタ**です。Word、Excel、PowerPoint、HTML、PDF などのファイルを Markdown に変換することもできます。すべての処理はお使いの Mac の中で行われ、ファイルがアップロードされることはありません。

画面は Swift / SwiftUI で作られており、macOS 26 以降では Liquid Glass のデザインになります。

---

## 1. インストール

Python のインストールやコマンドの入力は必要ありません。

### 動作環境

- Apple シリコン搭載の Mac（M1 / M2 / M3 / M4 …）
- macOS 14 以降（Liquid Glass の見た目は macOS 26 以降）

### 手順

1. `DropMD-macOS-AppleSilicon.dmg` をダブルクリックします。
2. 開いたウインドウで、矢印のとおりに **DropMD** のアイコンを右の「Applications」（アプリケーション）フォルダへドラッグします。
3. 初めて開くとき、macOS に「開発元を検証できません」と表示されることがあります。DropMD は有料の Apple デベロッパ署名を使っていないためです。開くには：
   - 「システム設定 → プライバシーとセキュリティ」を開き、下のほうにある DropMD についての表示で「このまま開く」をクリックします。
   - または（古い macOS の場合）Finder で DropMD.app を Control キーを押しながらクリックし、「開く」を選びます。
   この操作は最初の 1 回だけです。

---

## 2. エディタ

DropMD を開いたら、Markdown ファイルを新規作成するか開きます（「ファイル → 新規 / 開く」メニュー、または .md ファイルを Dock の DropMD アイコンにドラッグ）。初めて DropMD を開くと、Markdown ファイルを開くデフォルトのアプリにするかどうかを尋ねます。デフォルトにすると、Finder で .md ファイルをダブルクリックしたときに DropMD で開きます。あとから「DropMD → 設定…」（⌘,）で変更できます。デフォルトにしない場合も、Finder で .md ファイルを右クリックして「このアプリケーションで開く → DropMD」を選べば開けます。

画面の言語は Mac のシステム言語（簡体字中国語、繁体字中国語、英語、日本語）に合わせます。DropMD だけ別の言語にしたいときは、「DropMD → 設定…」の「言語」で選び、DropMD を再起動すると切り替わります。

ツールバー左端の「ページ / 分割」ボタンで、2 つの表示を切り替えます（⌘1 / ⌘2、または「表示」メニューでも切り替えられます）：

- **ページ**（標準、⌘1）：Pages や Word のようにそのまま書式を付けて書けます。**Markdown を知らなくても使えます**。見たままが仕上がりで、保存すると標準的な Markdown ファイルになります。
- **分割**（⌘2）：左に Markdown の原文、右に整形後のプレビューを表示します。Markdown に慣れている方や、数式の表示を確認したいときに向いています。

いつでも切り替えられ、内容は自動で同期します。右側の「フォーマット」パネル（ツールバー右の「フォーマット」ボタン、または ⌥⌘I）には、カーソル位置の段落スタイルと文字スタイルが表示され、クリックするだけで変更できます。表、画像、リンク、折りたたみセクションなどの挿入はツールバー中央にあります。すべてのコマンドは「フォーマット」と「挿入」メニューにあります。

### ページ表示の使い方

- **段落スタイル**：「フォーマット」パネルで、段落を本文、見出し 1～6、引用、コードブロックにできます（「フォーマット → コードブロック」でプログラミング言語を選べます。mermaid のフローチャートにも対応）。ショートカット：⌥⌘1～⌥⌘6 で見出し、⌥⌘0 で本文。
- **文字の書式**：太字（⌘B）、斜体（⌘I）、下線（⌘U）、取り消し線（⇧⌘X）、**ハイライト**（⇧⌘H）、インラインコード（⌥⌘C）、上付き（⌃⌘=）、下付き（⌃⌘-）、キーボードのキー表示。文字を選択してボタンを押すと付き、もう一度押すと外れます。何も選択していないときは、これから入力する文字にその書式が付きます。
- **リスト**：箇条書き、番号付き、**チェックリスト**（四角をクリックするとチェック）。リストの中で Tab を押すとインデントが深く、⇧Tab で浅くなります。空のリスト項目でもう一度 Return を押すとリストが終わります。
- **挿入**（ツールバー、「フォーマット」パネル、「挿入」メニュー）：
  - **リンク**（⌘K）、**画像**（この Mac の画像を選択）、**表**（最後のセルで Tab を押すと行が増え、Return で次のセルへ移動）、**区切り線**。
  - **折りたたみセクション**（⇧⌘D）：クリックで開いたり閉じたりできる部分です。タイトルは ▸ の後ろに、内容はその下の縦線のある部分に書きます。タイトル前の ▸ / ▾ をクリックすると閉じたり開いたりします（表示が変わるだけで、ファイルは変わりません。ファイルを開いたときはブラウザと同じく閉じた状態です）。タイトルで Return を押すと内容に入り、内容の空行でもう一度 Return を押すと折りたたみセクションから出ます。HTML に書き出したときや GitHub で見たときも、クリックで開けます。
  - **コールアウト**：注、ヒント、重要、警告、注意の 5 種類。1 行目にコールアウトの名前が表示され、その下に内容を書きます。「分割」のプレビュー、GitHub、Obsidian では色付きの枠で表示されます。
  - **脚注**（⌥⌘F）：カーソル位置に番号 [^1] を入れ、説明文は自動で文書の最後に置かれます。
  - **今日の日付**、**絵文字と記号**（システムの絵文字パレット）。
  - **改行（段落を分けない）**（⇧↩）：同じ段落の中で改行します。`<br>` として保存されます。
  - **インライン数式**（⌥⌘M）と**数式ブロック**（⇧⌥⌘M）：LaTeX で書きます（例：`E=mc^2`）。ページ表示でも数式として表示され、ダブルクリックで修正できます。
- **自動書式**：段落の先頭で `- `、`1. `、`# `、`> `、`[] ` と入力してスペースを押すと、箇条書き、番号付き、見出し、引用、チェックリストになります。中国語入力の `－ `、`1。 `、`＃ `、`》 `、`【】 ` も使えます。
- **貼り付け**：Web ページや Word から貼り付けると、太字、斜体、リンクなどは残り、色やフォントなど Markdown で保存できない書式は自動で取り除かれます。
- **リンク**：⌘ を押しながらクリックすると開きます。普通にクリックすると文字を編集できます。

### 分割表示

- 左で Markdown の原文を編集し、右にすぐプレビューが表示されます。スクロールすると左右の位置がそろいます。
- **シンタックスハイライト**：見出し、太字、斜体、コード、リンク、リスト、数式などを色や書体で区別して表示します。
- **数式**：`$E=mc^2$` はインライン数式、`$$ … $$` は独立した数式で、KaTeX で表示します。ChatGPT などの AI ツールがよく使う `\(E=mc^2\)` や `\[ … \]` も表示できます。`==ハイライト==` と脚注もプレビューできます。

### 共通の機能

- **画像**：この Mac の画像を挿入するときは、できるだけ文書からの相対パスを使います。プライバシー保護のため **Web 上の画像は読み込みません**。この Mac の画像は普通に表示されます。
- **自動保存**：編集内容は「テキストエディット」と同じように自動で保存されます。「ファイル → バージョンを戻す → すべてのバージョンをブラウズ」で以前の版を取り戻せます。名前のない新しい書類は、最初に保存するときに保存場所を尋ねます。
- **言語**：ウインドウ左下で文書の言語（簡体字中国語、繁体字中国語、日本語、韓国語）を選べます。同じ漢字でも中国語、日本語、韓国語で字形が違うため、言語を正しく選ぶと、その言語の字形で表示されます。書き出した PDF / HTML も同じです。標準は「自動」で、仮名があれば日本語、ハングルがあれば韓国語、それ以外はシステムの言語に合わせて簡体字か繁体字にします。手動で選んだ言語はファイルごとに記憶されます。
- **書き出し**：ツールバーの「書き出す」ボタン、または「フォーマット」メニュー：
  - **PDF として書き出す**：A4 サイズで自動的にページを分けます。
  - **HTML として書き出す**：1 つの HTML ファイルを作り、そのままブラウザで開けます。文書内のこの Mac の画像は HTML ファイルの中に埋め込まれるので、どのフォルダに保存しても、人に送っても表示されます。Web 上の画像は元のアドレスのまま参照します（ブラウザで開いたときに読み込まれます）。
- **クイックルック**：Finder で .md ファイルを選んでスペースキーを押すと、ファイルを開かずに整形後の見た目（分割表示のプレビューと同じ）を確認できます。文中のこの Mac の画像も表示します。そのために、クイックルックはホームフォルダと外付けディスクのファイルを**読み取りだけ**できます（変更はできず、ネットワークにも接続しません）。

## 3. ファイルの変換

ツールバーの「ファイルを変換」ボタン、または「ファイル → ファイルを Markdown に変換…」メニュー（⇧⌘T）で変換ウインドウを開きます。

1. **ファイルを追加**：ファイルやフォルダをウインドウにドラッグするか、「ファイルを選択… / フォルダを選択…」をクリックします。フォルダの場合は、中のすべてのサブフォルダにある対応ファイルが含まれます。
2. **モードを選ぶ**：
   - **高速**：MarkItDown を使い、すばやく変換します。Word、Excel、PowerPoint、HTML、CSV、文字の入った PDF に向いています。
   - **高精度**：Docling でレイアウト解析、表の認識、OCR による文字認識を行います。論文、表や数式のある PDF、スキャンした PDF に向いています。**PDF だけに使われ**、ほかの形式は高速モードで変換します。
3. **Word エンジン**（任意）：「Pandoc（レイアウト再現が良い）」を選ぶと、見出し、リスト、表などがより正確に再現されます。どちらのエンジンでも、Word 内の画像は `ファイル名_images` フォルダに書き出され、Markdown から相対パスで参照されます。
4. **OCR エンジン**（高精度モード）：最初の 2 つはダウンロード不要です。
   - **RapidOCR（標準）**：PP-OCRv6 の多言語モデルで、アプリに内蔵されています。同じページに簡体字中国語、繁体字中国語、日本語、英語などが混ざっていても、言語を選ばずに認識できます。韓国語とロシア語は認識できず、ベトナム語は声調記号の付いた文字が抜けます。これらの言語は Xiaomi-OCR-0 をお試しください（韓国語とベトナム語は誤字もあります）。
   - **Apple Vision**：macOS の「テキスト認識表示」で使われている文字認識エンジンで、macOS に内蔵されています。東アジアの言語は一度に 1 つしか主にできないため、選ぶと「主な言語」（簡体字中国語 / 繁体字中国語 / 日本語。英語は常に含まれます）も選びます。1 つの言語の文書に向いています。**中国語と日本語が混ざった文書には RapidOCR を使ってください**。
   - **Xiaomi-OCR-0**：Xiaomi（小米）がオープンソースで公開している文書認識モデルです（Apache-2.0。DropMD は Xiaomi とは関係ありません）。文字認識がより正確で、中国語・日本語・英語・フランス語・ドイツ語・スペイン語・ロシア語が混ざっていても読み取れ、数式と表も一緒に認識します（「数式を認識」をオンにする必要はありません）。初回は約 1.8 GB のダウンロードが必要です。ほかの 2 つより時間がかかります。M4 チップ、メモリ 16 GB の Mac では、文字がいっぱいのページで 1 ページ約 20～30 秒、変換中のメモリ使用量は最大で約 5 GB です（メモリ 8 GB の Mac では試していません）。**PDF 内の画像は書き出しません**。韓国語とベトナム語は誤字が多くなります。
5. **数式を認識**（高精度モード）：数式を LaTeX に変換します。時間がかかり、初回は追加のモデルのダウンロードが必要です。
6. **保存先**：
   - 標準では元のファイルと同じフォルダに、同じ名前で拡張子 `.md` として保存します。
   - 「指定したフォルダ」も選べます。フォルダを追加した場合は、サブフォルダの構成も保たれます。
7. **変換を開始** をクリックします。進行状況バーで全体の進み具合が、リストでファイルごとに「完了 / 失敗 / スキップ」が表示されます。失敗したときは「説明」欄に理由が表示されます。
8. 変換が終わったら、リストのファイルをダブルクリックすると、できた Markdown をエディタで開けます。右クリックで「Finder に表示」もできます。

**同じ名前のファイル**：書き出す `.md` がすでにある場合は、上書き、スキップ、すべて上書き、すべてスキップ、キャンセルのどれにするかを先に尋ねます。

**元のファイルは変更されません**：元のファイルは読み取るだけで、結果は必ず新しい `.md` ファイル（と画像フォルダ）に書き出します。

## 4. 初めて使うとき

- **高速モードと Pandoc**：ネットワークに接続せず、すぐに使えます。
- **初めて高精度モードを使う**とき、ダウンロードが必要な認識モデル、それぞれの**ダウンロード元**と**サイズ**、保存場所を一覧にしたウインドウが表示されます。「同意してダウンロード」をクリックしたときだけダウンロードが始まり、「キャンセル」なら何もダウンロードしません。
  - ダウンロードするのは Docling のレイアウト解析（約 172 MB）、表の認識（約 358 MB）、任意の数式認識（約 640 MB）のモデルだけで、Hugging Face にある Docling の公式アカウント（`huggingface.co/docling-project`）から取得します。
  - OCR はダウンロード不要です。Apple Vision は macOS に内蔵され、RapidOCR のモデルは PyPI のパッケージに含まれていてアプリに内蔵済みです。
  - Xiaomi-OCR-0 を選んだ場合は、そのモデル（約 1.8 GB）だけを Hugging Face にある Xiaomi の公式アカウント（`huggingface.co/xiaomi-research`）からダウンロードします。Docling のモデルは必要ありません。
  - モデルの保存場所：`~/Library/Application Support/DropMD/models`
  - ダウンロードには macOS のシステムネットワーク（Safari と同じネットワーク、DNS、プロキシ設定。PAC 自動プロキシと SOCKS プロキシにも対応）を使い、huggingface.co とそのダウンロードサーバだけに接続し、Cookie は保存しません。各ファイルはダウンロード後に完全性を確認します。途中で失敗しても、やり直すときに完了済みのファイルは再ダウンロードしません。
  - ダウンロード後の変換は完全にオフラインです。「高精度認識モデル」メニューから手動でダウンロードしたり、モデルのフォルダを開いたりもできます。モデルを削除するには、そのフォルダを削除してください。
- 初めて高精度で変換するときは、モデルの読み込みに少し時間がかかります（Mac の性能により数十秒ほど）。2 回目からはずっと速くなります。

## 5. ソフトウェア・アップデート

「DropMD → アップデートを確認…」メニューで「ソフトウェア・アップデート」ウインドウを開きます：

- 現在のバージョンが表示されます。「今すぐ確認」で GitHub に新しいバージョンとその説明があるかを確認します。
- 新しいバージョンがあれば「ダウンロードしてアップデート」をクリックします。DropMD がインストール用ファイルをダウンロードして**完全性を確認**し、終わったら「再起動」で新しいバージョンに切り替わります（保存していない書類があるときは、先に保存するか尋ねます）。アップデート後、「ダウンロード」フォルダにある以前の DropMD のインストール用ファイルはゴミ箱に移されます。DropMD が「アプリケーション」など書き込める場所にない場合は、インストール用ファイルを開くので、案内に従って DropMD を「アプリケーション」にドラッグして古いバージョンを置き換えてください。
- **起動時にアップデートを自動的に確認**：初めて起動したときに、オンにするかどうか尋ねます。オンにすると起動のたびに 1 回確認し、新しいバージョンがあればお知らせします。ダウンロードするかどうかはご自身で決められ、自動でインストールされることはありません。
- **ベータ版を含める**：オンにするとベータ版もお知らせします。いまベータ版を使っている場合は標準でオンです。
- アップデートの確認では GitHub にバージョン番号と説明を問い合わせるだけで、ファイルや個人情報は送りません。

## 6. プライバシーとセキュリティ

- 変換はすべてこの Mac の中で行い、ファイルの内容をサーバやオンライン API に送ることはありません。
- 変換エンジンは、外部へのネットワーク接続を内部ですべて遮断します（この Mac の中での通信だけ許可）。
- ネットワークに接続するのは次の 2 つだけで、どちらもあなたの同意が必要です：高精度モードの認識モデルのダウンロード、アップデートの確認（GitHub に新しいバージョンを問い合わせる）。どちらもアプリが macOS のシステムネットワークを使って行います。
- データ収集、利用統計、広告はありません。勝手に何かをインストールすることもありません。
- 前回の設定（モード、保存先など）を覚えますが、この Mac の中にだけ保存します。
- Markdown のプレビューには厳しいコンテンツセキュリティポリシーを設定しています。この Mac のファイルしか読めず、ネットワークへのリクエストや文書に埋め込まれたスクリプトは実行できません。
- 使っているオープンソースのコンポーネントとバージョンは、「ヘルプ → オープンソースライセンス：サードパーティ製コンポーネント」と、プロジェクトの `docs/依赖清单.md` をご覧ください。

## 8. 制限事項

- **対応形式**：`.docx`、`.xlsx`、`.pptx`、`.html/.htm`、`.pdf`、`.csv`。古い Office の形式（`.doc`、`.xls`、`.ppt`）には対応していません。先に Office で新しい形式で保存してください。
- **暗号化された、またはパスワード付きのファイル**は変換できません。
- **高速モード**：PDF は文字だけを取り出すため、複雑なレイアウトや表が崩れることがあります。スキャンした PDF からは文字を取り出せません（高精度モードを使うよう案内します）。
- **高精度モード**：メモリを多く使い（8 GB 以上を推奨）、大きなファイルは数分かかることがあります。手書き文字や非常にぼやけたスキャンはうまく認識できないことがあります。
- **Liquid Glass** の見た目には macOS 26 以降が必要です。macOS 14～15 でも同じように使えますが、通常の半透明の見た目になります。
- **Pandoc エンジン**は Word（.docx）だけに使われます。
- **エディタ**：非常に大きなファイル（数 MB 以上）ではシンタックスハイライトとプレビューが遅くなります。プレビューでは Web 上の画像とフォントを読み込みません。
- **ページ表示**で保存されるのは Markdown で表せる書式だけです。フォント、文字サイズ、文字の色、配置などは保存できません（そのためツールバーにこれらのボタンはありません）。Web ページや Word から貼り付けた文字は、太字、斜体、リンクなどは残り、それ以外の書式は保存時に取り除かれます。
- ページ表示が対応していない Markdown の内容（一般的な HTML、入れ子になった折りたたみセクション、ファイル先頭の YAML 情報、参照形式のリンクのアドレス、リスト項目の中の続きの段落、引用の中のリストなど）は等幅の文字で表示され、**そのまま保存**されるので失われません。リスト項目の下にコードブロックだけが続く場合（AI ツールがインストール手順をよくこう書きます）は、ページ表示でそのまま編集できます。
- ページ表示で編集して保存すると、変更していない段落はそのまま残ります。変更した段落では、一部の書き方が同じ意味の標準的な書き方に変わります：行末の 2 つのスペースやバックスラッシュによる改行は `<br>` に、4 つのスペースでインデントしたコードは ``` のコードブロックに、`===` の下線式の見出しは `#` の見出しに、`*` の箇条書きは `-` の箇条書きに、引用で `>` のない続きの行には `>` を補う、などです。
- アプリのサイズは大きめです（実際のビルドによります）。主に高精度モードに必要な PyTorch などのためです。
- アプリには Apple のデベロッパ署名がないため、初めて開くときは上記の手順で許可してください。
- Intel プロセッサ搭載の Mac には対応していません（高精度モードが使う PyTorch が Intel Mac 版を提供していないためです）。
- ネットワークの遮断は、変換エンジンの Python コード（すべての変換ライブラリの Python 部分を含む）に対して働きます。Swift の画面側でネットワークを使うのは、モデルのダウンロードとアップデートの確認の 2 か所だけで、どちらもあなたの同意が必要です。さらに安心したい場合は、ファイアウォールのソフトで DropMD のネットワーク接続を禁止し、モデルのダウンロードやアップデートのときだけ一時的に許可してください。
