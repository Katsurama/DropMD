## DropMD 0.1.0-beta.3（测试版）

**新功能**
- 文档语言：窗口左下角可以选择简体中文、繁体中文（香港 / 台湾）、日语、韩语。同一个汉字在各语言里写法不同，选对语言，汉字就按该语言的写法显示，导出的 PDF / HTML 也一样。默认“自动”：有假名按日语，有韩文按韩语。手动选择会按文件记住
- 中文改用小米 MiSans 字体（简体 MiSans、繁体 MiSans TC，免费商用）；日语、韩语使用系统自带字体

**修复**
- 导出 HTML 时提示“发生了 JavaScript 异常”，无法导出
- 单页：提示框的标题显示为 `[!TIP]` 原文，现在显示“提示”“注意”等（保存的文件不变）
- 单页：文末脚注说明行开头的编号被显示成上标
- 文件转换（快速模式）：Word 里没有标题行的表格多出一行空表头
- 文件转换（快速模式）：Word / PowerPoint 里的图片只留下一行说明文字，现在导出到“文件名_images”文件夹

**隐私**
- 关闭了转换组件 onnxruntime 内置的统计上报

## DropMD 0.1.0-beta.1（首个公开测试版）

Mac 上的离线 Markdown 编辑器，还能把 Word、Excel、PowerPoint、PDF 等文件转换为 Markdown。全部在本机完成，不上传文件。

**编辑**
- 单页：像 Pages / Word 一样直接排版，不用会写 Markdown，保存的仍是标准 Markdown 文件
- 双页：左边 Markdown 原文，右边实时预览
- 标题、粗体、斜体、下划线、删除线、高亮、列表、待办、表格、图片、链接、代码块
- 提示框（与 GitHub 相同的写法）、折叠块、脚注、数学公式、上标 / 下标、键盘按键
- 段首输入“- ”“1. ”“# ”“> ”等自动变格式，中文输入法的全角符号也可以
- 导出 PDF、HTML；自动保存和版本历史

**文件转换**
- 快速模式（MarkItDown）、Word 高质量模式（Pandoc）、高精度模式（Docling + OCR）
- 不需要安装 Python，转换引擎已经打包在 App 里

**软件更新**
- 在 App 里检查新版本（需要你同意），下载后校验完整性，点“重新启动”即完成

**安装**：下载 `DropMD-macOS-AppleSilicon.dmg`（Apple 芯片的 Mac，macOS 14 及以上），打开后把 DropMD 拖到“应用程序”。第一次打开如果提示无法验证开发者，到“系统设置 → 隐私与安全性”点“仍要打开”。

这是测试版，可能还有问题，欢迎在 Issues 里反馈。
