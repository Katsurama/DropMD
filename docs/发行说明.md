## DropMD 0.2.0

**新功能**
- “DropMD → 设置…”里可以单独选择界面语言、外观，以及启动时是否自动检查更新
- 更好地支持 ChatGPT、Claude 等 AI 工具写出的 Markdown：`\(…\)` 和 `\[…\]` 公式能显示；粗体贴着标点（如 `**“重点”**内容`）也能正确加粗；列表项下面的代码块可以在单页里直接修改
- 快速查看能显示文档里的本机图片（为此快速查看可以只读你的个人文件夹和外接硬盘，不能修改，也不联网）
- 软件更新窗口只显示当前界面语言的更新说明
- 繁体中文界面下，文件转换的提示也显示繁体

**改进**
- 打开“格式”面板时，工具栏中间的按钮也在窗口正中
- 日文界面：“1 ページ / 2 ページ”改为“ページ / 分割”

**修复**
- 单页改过再保存，不再丢掉链接 / 图片的提示文字、段落里的换行、多行脚注；引用里不带 > 的续行、列表项的续行保持原样
- 单页保存时，编号列表下的子列表缩进正确（原来在别的软件里会变成同级）
- 粘贴或拖入网页、文本编辑里的内容时，链接保留网址，列表变成真正的列表
- 导出 HTML：`<img width="200" src="…">` 这类写法的本机图片也会放进文件

**English**
- DropMD → Settings… now lets you choose the interface language, the appearance, and whether to check for updates at launch
- Better support for Markdown written by AI tools such as ChatGPT and Claude: `\(…\)` and `\[…\]` math, bold text next to Chinese punctuation, and code blocks inside list items (now editable in Page view)
- Quick Look shows local images in the document (Quick Look may now read, but not change, files in your home folder and on external drives; it never goes online)
- The update window shows the release notes in your interface language only
- Page view no longer loses link and image titles, line breaks, multi-line footnotes, quote and list continuation lines, or nested list indentation when saving
- Pasting or dropping content from web pages or TextEdit keeps link addresses and real lists

**日本語**
- 「DropMD → 設定…」で表示言語、外観、起動時のアップデート確認を個別に選べるようになりました
- ChatGPT や Claude などの AI ツールが書く Markdown に対応：`\(…\)`・`\[…\]` の数式、句読点に隣接した太字、リスト項目内のコードブロック（ページ表示で直接編集可能）
- クイックルックで書類内のローカル画像を表示（そのためクイックルックはホームフォルダと外付けドライブのファイルを読み取り専用で参照します。変更やネット接続はしません）
- アップデートのウインドウには表示言語のリリースノートだけを表示
- 日本語表示で「1 ページ / 2 ページ」を「ページ / 分割」に変更
- ページ表示で保存したときに、リンクの説明、改行、複数行の脚注、入れ子のリストのインデントなどが崩れないよう修正

**繁體中文**
- 「DropMD → 設定⋯」可以單獨選擇介面語言、外觀，以及啟動時是否自動檢查更新
- 更好地支援 ChatGPT、Claude 等 AI 工具寫出的 Markdown：`\(…\)` 和 `\[…\]` 公式、緊貼標點的粗體、清單項目下的程式碼區塊（可在單頁裡直接修改）
- 快速查看能顯示文件中的本機圖片（快速查看因此可以唯讀你的個人資料夾和外接硬碟，不會修改，也不連網）
- 軟體更新視窗只顯示目前介面語言的更新說明；繁體中文介面下，檔案轉換的提示也是繁體
- 單頁修改後儲存，不再遺失連結與圖片的提示文字、段落中的換行、多行註腳、巢狀清單的縮排
- 貼上或拖入網頁、文字編輯中的內容時，連結保留網址，清單變成真正的清單

## DropMD 0.1.0

**新功能**
- 快速查看（Quick Look）：在访达里选中 .md 文件按空格，不用打开就能看到排版后的样子
- 日文界面、繁体中文界面（台湾用语）：跟随 Mac 的系统语言
- 单页：公式显示为数学符号，双击可以修改
- 单页：折叠块可以点 ▸ 收起、展开
- 开启“自动检查更新”后，每次打开 App 都会检查（原来一天最多查一次）

**修复**
- 单页改过再保存，不再改坏这些写法：文件开头的 YAML 信息、引用式链接、强制换行、缩进的代码、不从 1 开始的编号、列表项里的段落和代码、引用里的列表、表格的对齐方式、`===` 标题
- 单页：刚打完字马上关窗或退出，最后几个字不会丢
- 单页：在公式后面打的字不会变成公式；复制粘贴不再丢公式和图片
- 单页：折叠块里的表格缩进对齐；`<details open>` 保存后不再丢掉 open
- 双页预览、快速查看：文件开头的 YAML 信息显示为代码块，不再变成横线加大标题
- 导出 HTML：文中的本机图片直接放进文件，存到哪里都能显示；网络图片不再被换成提示文字
- 文件转换：不再删除或覆盖“文件名_images”文件夹里你自己的图片

**English**
- Quick Look: select a .md file in Finder and press Space to see it formatted without opening it
- Japanese and Traditional Chinese interfaces, following your Mac's language
- Page view shows math formulas as rendered math (double-click to edit) and lets you collapse and expand collapsible sections
- Editing in Page view no longer breaks YAML front matter, reference links, line breaks, indented code, list numbering, table alignment and other syntax when saving
- The last characters typed are no longer lost when closing a window right away
- Exported HTML embeds local images; file conversion no longer deletes or overwrites your own images

**日本語**
- クイックルック：Finder で .md ファイルを選んでスペースキーを押すと、開かずに書式付きで確認できます
- 日本語と繁体字中国語のインターフェイス（Mac の言語設定に合わせて切り替わります）
- 1 ページ表示で数式をきれいに表示（ダブルクリックで編集）、折りたたみセクションの開閉に対応
- 1 ページ表示で編集して保存しても、YAML フロントマター、参照リンク、改行、インデントされたコード、番号付きリストの番号、表の配置などが崩れなくなりました

## DropMD 0.1.0-beta.1（首个公开测试版）

Mac 上的离线 Markdown 编辑器，还能把 Word、Excel、PowerPoint、PDF 等文件转换为 Markdown。全部在本机完成，不上传文件。

**编辑**
- 单页：像 Pages / Word 一样直接排版，不用会写 Markdown，保存的仍是标准 Markdown 文件
- 双页：左边 Markdown 原文，右边实时预览
- 标题、粗体、斜体、下划线、删除线、高亮、列表、待办、表格、图片、链接、代码块
- 提示框（与 GitHub 相同的写法）、折叠块、脚注、数学公式、上标 / 下标、键盘按键
- 段首输入“- ”“1. ”“# ”“> ”等自动变格式，中文输入法的全角符号也可以
- 导出 PDF、HTML；自动保存和版本历史

**文件转换**
- 快速模式（MarkItDown）、Word 高质量模式（Pandoc）、高精度模式（Docling + OCR）
- 不需要安装 Python，转换引擎已经打包在 App 里

**软件更新**
- 在 App 里检查新版本（需要你同意），下载后校验完整性，点“重新启动”即完成

**安装**：下载 `DropMD-macOS-AppleSilicon.dmg`（Apple 芯片的 Mac，macOS 14 及以上），打开后把 DropMD 拖到“应用程序”。第一次打开如果提示无法验证开发者，到“系统设置 → 隐私与安全性”点“仍要打开”。

这是测试版，可能还有问题，欢迎在 Issues 里反馈。
