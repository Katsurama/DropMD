## DropMD 0.1.0

**新功能**
- 快速查看（Quick Look）：在访达里选中 .md 文件按空格，不用打开就能看到排版后的样子
- 日文界面、繁体中文界面（台湾用语）：跟随 Mac 的系统语言
- 单页：公式显示为数学符号，双击可以修改
- 单页：折叠块可以点 ▸ 收起、展开
- 开启“自动检查更新”后，每次打开 App 都会检查（原来一天最多查一次）

**修复**
- 单页改过再保存，不再改坏这些写法：文件开头的 YAML 信息、引用式链接、强制换行、缩进的代码、不从 1 开始的编号、列表项里的段落和代码、引用里的列表、表格的对齐方式、`===` 标题
- 单页：刚打完字马上关窗或退出，最后几个字不会丢
- 单页：在公式后面打的字不会变成公式；复制粘贴不再丢公式和图片
- 单页：折叠块里的表格缩进对齐；`<details open>` 保存后不再丢掉 open
- 双页预览、快速查看：文件开头的 YAML 信息显示为代码块，不再变成横线加大标题
- 导出 HTML：文中的本机图片直接放进文件，存到哪里都能显示；网络图片不再被换成提示文字
- 文件转换：不再删除或覆盖“文件名_images”文件夹里你自己的图片

**English**
- Quick Look: select a .md file in Finder and press Space to see it formatted without opening it
- Japanese and Traditional Chinese interfaces, following your Mac's language
- Page view shows math formulas as rendered math (double-click to edit) and lets you collapse and expand collapsible sections
- Editing in Page view no longer breaks YAML front matter, reference links, line breaks, indented code, list numbering, table alignment and other syntax when saving
- The last characters typed are no longer lost when closing a window right away
- Exported HTML embeds local images; file conversion no longer deletes or overwrites your own images

**日本語**
- クイックルック：Finder で .md ファイルを選んでスペースキーを押すと、開かずに書式付きで確認できます
- 日本語と繁体字中国語のインターフェイス（Mac の言語設定に合わせて切り替わります）
- 1 ページ表示で数式をきれいに表示（ダブルクリックで編集）、折りたたみセクションの開閉に対応
- 1 ページ表示で編集して保存しても、YAML フロントマター、参照リンク、改行、インデントされたコード、番号付きリストの番号、表の配置などが崩れなくなりました

## DropMD 0.1.0-beta.3（测试版）

**新功能**
- 文档语言：窗口左下角可以选择简体中文、繁体中文（香港 / 台湾）、日语、韩语。同一个汉字在各语言里写法不同，选对语言，汉字就按该语言的写法显示，导出的 PDF / HTML 也一样。默认“自动”：有假名按日语，有韩文按韩语。手动选择会按文件记住

- 单页：提示框的标题显示为 `[!TIP]` 原文，现在显示“提示”“注意”等（保存的文件不变）
- 单页：文末脚注说明行开头的编号被显示成上标
- 文件转换（快速模式）：Word 里没有标题行的表格多出一行空表头
- 文件转换（快速模式）：Word / PowerPoint 里的图片只留下一行说明文字，现在导出到“文件名_images”文件夹

**隐私**
- 关闭了转换组件 onnxruntime 内置的统计上报

## DropMD 0.1.0-beta.1（首个公开测试版）

Mac 上的离线 Markdown 编辑器，还能把 Word、Excel、PowerPoint、PDF 等文件转换为 Markdown。全部在本机完成，不上传文件。

**编辑**
- 单页：像 Pages / Word 一样直接排版，不用会写 Markdown，保存的仍是标准 Markdown 文件
- 双页：左边 Markdown 原文，右边实时预览
- 标题、粗体、斜体、下划线、删除线、高亮、列表、待办、表格、图片、链接、代码块
- 提示框（与 GitHub 相同的写法）、折叠块、脚注、数学公式、上标 / 下标、键盘按键
- 段首输入“- ”“1. ”“# ”“> ”等自动变格式，中文输入法的全角符号也可以
- 导出 PDF、HTML；自动保存和版本历史

**文件转换**
- 快速模式（MarkItDown）、Word 高质量模式（Pandoc）、高精度模式（Docling + OCR）
- 不需要安装 Python，转换引擎已经打包在 App 里

**软件更新**
- 在 App 里检查新版本（需要你同意），下载后校验完整性，点“重新启动”即完成

**安装**：下载 `DropMD-macOS-AppleSilicon.dmg`（Apple 芯片的 Mac，macOS 14 及以上），打开后把 DropMD 拖到“应用程序”。第一次打开如果提示无法验证开发者，到“系统设置 → 隐私与安全性”点“仍要打开”。

这是测试版，可能还有问题，欢迎在 Issues 里反馈。
