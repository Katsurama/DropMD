# 👋 欢迎使用 DropMD

DropMD 是一个 Mac 上的 Markdown 编辑器：**像 Word 一样直接排版**，保存下来就是标准的 Markdown 文件。它还能把 Word、Excel、PowerPoint、PDF 等文件转换成 Markdown。

> [!TIP]
> 这份说明本身就是一个 Markdown 文档，你可以随便在上面点点、改改，试试各种功能。不用担心改坏：每次从菜单“帮助 → 使用说明”打开的都是一份新的。

## 🚀 3 步上手

- [ ] 菜单“文件 → 新建”（⌘N），新建一个文档
- [ ] 在第一行输入 `# ` 再打字，它就变成了大标题；换行后直接写正文
- [ ] 选中几个字，按 ⌘B 加粗。写完关窗口时选个地方保存，就得到一个 `.md` 文件

> [!NOTE]
> 不需要会写 Markdown。看到的就是最终效果，格式会在保存时自动写成 Markdown。

## ✍️ 写文档

### 单页和双页

工具栏最左边可以切换两种显示方式：

| 方式 | 快捷键 | 适合 |
| --- | --- | --- |
| **单页** | ⌘1 | 像 Word、Pages 一样直接排版，看到的就是效果 |
| **双页** | ⌘2 | 左边 Markdown 原文，右边单页；两边都能改，内容和滚动实时同步 |

在双页的左边移动光标时，右边会标出对应的位置。不想要可以在“DropMD → 设置… → 通用”里关掉，或者换一种标记样式（边框、侧边线、光标）。中间的分隔线可以拖动，双击回到一半一半。

### 打字时自动变格式

在一段的开头输入下面这些符号，再按空格：

| 输入 | 变成 |
| --- | --- |
| `# ` `## ` `### ` | 标题 1、2、3 |
| `- ` 或 `* ` | 项目符号列表 |
| `1. ` | 编号列表 |
| `[] ` | 待办清单（点方框就能勾选） |
| `> ` | 引用 |

> [!TIP]
> 中文输入法下的 `－`、`1。`、`＃`、`》`、`【】` 也可以，不用切换到英文。

### 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 粗体 / 斜体 / 下划线 | ⌘B / ⌘I / ⌘U |
| 删除线 / 高亮 | ⇧⌘X / ⇧⌘H |
| 行内代码 | ⌥⌘C |
| 标题 1～6 / 正文 | ⌥⌘1～⌥⌘6 / ⌥⌘0 |
| 链接 / 图片 | ⌘K / ⇧⌘K |
| 表格 | ⌥⌘T |
| 增加 / 减少缩进 | Tab / ⇧Tab（在列表里） |
| 同一段里换行 | ⇧↩ |
| 显示“格式”面板 | ⌥⌘I |

所有命令都能在菜单“格式”和“插入”里找到。右边的“格式”面板会显示光标处的样式，点一下就能改。

### 右键菜单

在不同的东西上点右键，会出现对应的常用操作：

- **表格**：插入行或列、删除行或列、对齐方式、复制表格、删除表格
- **链接**：打开、编辑、复制、移除
- **图片**：编辑替代文本、在访达中显示、删除
- **代码块**：复制代码、选择语言
- **提示框**：换类型、转换为引用
- **选中的文字**：删除线、高亮、行内代码、清除格式

## 📦 插入各种内容

点工具栏中间的按钮，或使用菜单“插入”。

### 表格

- 按 Tab 或回车移到下一格；在最后一格按 Tab 自动加一行，按回车跳到表格下面
- 拖动两列中间的线可以调整列宽
- 选中整行按退格删除这几行；在表格下面一段的开头按两下退格，删除整张表格（第一下先选中，防止误删）

### 提示框

就是你现在看到的这种带颜色的方框，有“注意、提示、重要、警告、小心”五种：

> [!IMPORTANT]
> 提示框在 GitHub 和 Obsidian 里也会显示成带颜色的方框。

### 代码块

把段落设为代码块后，可以在右键菜单里选编程语言。鼠标移到代码块上，右上角会出现“复制”按钮：

```swift
print("Hello, DropMD!")
```

### 折叠块

<details>
<summary>点击这里展开看看</summary>

折叠块可以把一段内容收起来，点击标题前的三角展开或收起。插入折叠块的快捷键是 ⇧⌘D。

</details>

### 公式、脚注和其他

- **公式**：行内公式 ⌥⌘M，公式块 ⇧⌥⌘M，用 LaTeX 书写，例如 $E=mc^2$。双击公式可以修改
- **脚注**：⌥⌘F 在光标处插入编号，说明文字自动放到文档末尾
- **图片**：插入本机图片时会尽量用相对于文档的路径。为了保护隐私，**不会加载在线图片**
- **今天的日期**、**表情与符号**：在菜单“插入”里

## 🔗 链接

点击链接时，默认先问一下再打开，免得想改链接文字时误打开。可以在“DropMD → 设置… → 通用 → 点击链接时”改成“直接打开”或“按住 ⌘ 点击才打开”。按住 ⌘ 点击总是直接打开。

链接到另一个 `.md` 文件时，会用 DropMD 打开它；链接到其他文件时，会在访达中显示。

## 📤 保存、导出和分享

- **自动保存**：和“文本编辑”一样自动保存。想找回以前的内容，用菜单“文件 → 恢复到 → 浏览所有版本”
- **导出**：工具栏的“导出”按钮，可以导出 **PDF**（A4 纸张）或 **HTML**（文档里的本机图片会直接放进 HTML 文件，发给别人也能显示）
- **分享**：工具栏的“分享”按钮，通过隔空投送、邮件、信息等把这个 `.md` 文件发出去
- **快速查看**：在访达里选中 `.md` 文件按空格，不用打开就能看到排版后的效果

> [!TIP]
> 窗口左下角可以选择文档语言（简体中文、繁体中文、日语、韩语）。同一个汉字在中文、日语、韩语里写法不同，选对语言，汉字才会按该语言的写法显示。

## 🔄 把文件转换成 Markdown

菜单“文件 → 转换文件为 Markdown…”（⇧⌘T）打开转换窗口：

1. 把文件或整个文件夹拖进窗口，也可以点“选择文件…”
2. 选择模式：
   - **快速**：适合 Word、Excel、PowerPoint、HTML、CSV 和文字型 PDF
   - **高精度**：适合论文、扫描版 PDF、带表格或公式的 PDF（只对 PDF 生效）
3. 点“开始转换”。完成后，双击列表里的文件就能用 DropMD 打开

转换好的 `.md` 默认放在原文件旁边，Word 里的图片会导出到“文件名_images”文件夹。**原文件不会被修改。**

> [!NOTE]
> 第一次用高精度模式时，需要下载识别模型（约 530 MB，选“识别数学公式”时再加约 640 MB）。下载前会列出来源和大小，你同意后才会下载；下载一次之后就能离线使用。

| OCR 引擎（高精度模式） | 特点 |
| --- | --- |
| **RapidOCR**（默认） | 同一页里的简体、繁体、日文、英文可以混在一起识别 |
| **Apple Vision** | macOS 自带，适合只有一种语言的文档，需要选择主要语言 |
| **Xiaomi-OCR-0** | 更准，公式和表格一起识别；第一次要下载约 1.8 GB，速度较慢 |

## ⚙️ 设置

菜单“DropMD → 设置…”（⌘,）分为四页：

| 页面 | 可以做什么 |
| --- | --- |
| **通用** | 外观（浅色 / 深色）、页边距、点击链接时、双页的位置标记、界面语言、设为 `.md` 的默认打开程序 |
| **更新** | 检查新版本、启动时自动检查、包括测试版 |
| **赞助** | 喜欢 DropMD 的话，可以请作者喝杯咖啡 |
| **关于** | 版本号、GitHub 仓库、反馈问题、交流群、开源许可 |

> [!TIP]
> 新版本会先发测试版。想抢先用新功能，就在“更新”页勾选“包括测试版”。

## 🔒 隐私

- 所有编辑和转换都在你自己的 Mac 上完成，不会上传任何文件
- 只有两件事会联网，而且都要你同意：下载高精度模式的识别模型、检查更新
- 没有数据收集、使用统计或广告，不会自动安装任何东西

## ❓ 常见问题

<details>
<summary>保存后，有些格式不见了？</summary>

Markdown 只能保存粗体、斜体、标题、列表、表格这类格式。字体、字号、文字颜色、对齐方式等无法保存，所以工具栏里也没有这些按钮。从网页或 Word 粘贴时，粗体、斜体、链接会保留，其他格式会去掉。

</details>

<details>
<summary>文档里有些内容显示成等宽文字？</summary>

单页暂时不支持的写法（例如一般的 HTML 代码、文件开头的 YAML 信息）会这样显示，并原样保存，不会丢失。切到双页就能在左边直接修改。

</details>

<details>
<summary>哪些文件可以转换？</summary>

`.docx`、`.xlsx`、`.pptx`、`.html`、`.pdf`、`.csv`。旧版 Office 格式（`.doc`、`.xls`、`.ppt`）请先用 Office 另存为新格式；加密或有密码的文件无法转换。

</details>

<details>
<summary>遇到问题去哪里反馈？</summary>

菜单“帮助 → 反馈问题…”会打开 GitHub 的问题页面。也可以在“帮助”菜单里加入 QQ 交流群或 Discord 社区。

</details>
