# DropMD 使用说明

DropMD 是一个 Mac 上的 **Markdown 编辑器**，同时可以把 Word、Excel、PowerPoint、HTML、PDF 等文件转换成 Markdown。所有操作都在您自己的 Mac 上完成，不会上传任何文件。

界面用 Swift / SwiftUI 原生开发，在 macOS 26 及以上采用 Liquid Glass 设计。

---

## 一、安装

不需要安装 Python，也不需要输入任何命令。

### 系统要求

- Apple 芯片的 Mac（M1 / M2 / M3 / M4 …）
- macOS 14 或更高版本（macOS 26 及以上可显示 Liquid Glass 玻璃效果）

### 安装步骤

1. 双击 `DropMD-macOS-AppleSilicon.dmg`。
2. 在打开的安装窗口中，按照箭头提示，把 **DropMD** 图标拖到右边的“应用程序”文件夹。
3. 第一次打开时，macOS 可能会提示“无法验证开发者”，因为本程序没有付费购买 Apple 开发者签名。处理方法：
   - 打开“系统设置 → 隐私与安全性”，在页面下方找到关于 DropMD 的提示，点“仍要打开”；
   - 或在 Finder 中按住 Control 点击 DropMD.app，选择“打开”（较早的 macOS 版本有效）。
   这个操作只需要做一次。

## 二、编辑器

打开 DropMD 后，可以新建或打开 Markdown 文件（菜单“文件 → 新建 / 打开”，或把 .md 文件拖到 Dock 上的 DropMD 图标上）。在访达中右键 .md 文件，选“打开方式 → DropMD”也可以；DropMD 不会抢占 .md 文件的默认打开程序。

工具栏最左边的“单页 / 双页”按钮可以切换两种显示方式（也可以按 ⌘1 / ⌘2，或使用菜单“显示”）：

- **单页**（默认，⌘1）：像 Pages / Word 一样直接排版，**不需要会写 Markdown**。看到的就是最终效果，保存时自动转换为标准的 Markdown 文件。
- **双页**（⌘2）：左边是 Markdown 原文，右边是排版后的预览。适合熟悉 Markdown 的用户，或需要查看数学公式效果时使用。

两种方式随时可以切换，内容自动同步。右侧的“格式”面板（工具栏右边的“格式”按钮，或 ⌥⌘I）显示光标处的段落样式和文字样式，点一下即可修改。插入表格、图片、链接、折叠块等在工具栏中间；全部命令都在菜单“格式”和“插入”中。

### 单页怎么用

- **段落样式**：在“格式”面板中可以把段落设为正文、标题 1～6、引用或代码块（菜单“格式 → 代码块”可选择编程语言，包括 mermaid 流程图）。快捷键：⌥⌘1～⌥⌘6 为标题，⌥⌘0 为正文。
- **文字格式**：粗体（⌘B）、斜体（⌘I）、下划线（⌘U）、删除线（⇧⌘X）、**高亮**（⇧⌘H）、行内代码（⌥⌘C）、上标（⌃⌘=）、下标（⌃⌘-）、键盘按键样式。选中文字后点按钮即可，再点一次取消。不选文字时，接下来输入的文字会使用该格式。
- **列表**：项目符号、编号、**待办清单**（点击方框即可勾选）。在列表中按 Tab 增加缩进、⇧Tab 减少缩进；在空的列表项上再按一次回车即结束列表。
- **插入**（工具栏、“格式”面板或菜单“插入”）：
  - **链接**（⌘K）、**图片**（选择本机图片）、**表格**（在最后一格按 Tab 自动增加一行，按回车移到下一格）、**分隔线**；
  - **折叠块**（⇧⌘D）：一个可以点击展开 / 收起的区域，标题写在 ▸ 后面，内容写在下面带竖线的区域里。在标题上按回车进入内容；在内容的空行上再按回车即离开折叠块。导出 HTML 或在 GitHub 上查看时可以点击展开；
  - **提示框**：注意、提示、重要、警告、小心五种，第一行显示为 `[!NOTE]` 等，下面写内容。在“双页”预览、GitHub 和 Obsidian 中显示为带颜色的方框；
  - **脚注**（⌥⌘F）：在光标处插入编号 [^1]，说明文字自动放到文档末尾；
  - **今天的日期**、**表情与符号**（系统的表情面板）；
  - **换行（不分段）**（⇧↩）：在同一段落内换行，保存为 `<br>`；
  - **行内公式**（⌥⌘M）和 **公式块**（⇧⌥⌘M）：用 LaTeX 书写，例如 `E=mc^2`。单页中公式以紫色文字显示，在“双页”的预览和导出的文件中显示为数学符号。
- **自动格式**：在段落开头输入 `- `、`1. `、`# `、`> `、`[] ` 后按空格，会自动变成列表、编号、标题、引用、待办。中文输入法下的 `－ `、`1。 `、`＃ `、`》 `、`【】 ` 也可以。
- **粘贴**：从网页或 Word 粘贴时保留粗体、斜体、链接等，颜色、字体等 Markdown 无法保存的格式会自动去掉。
- **链接**：按住 ⌘ 点击链接才会打开，普通点击用于编辑文字。

### 双页

- 左边编辑 Markdown 原文，右边实时预览，滚动时两边自动对齐。
- **语法高亮**：标题、粗体、斜体、代码、链接、列表、公式等用不同的颜色和字体显示。
- **数学公式**：`$E=mc^2$` 为行内公式，`$$ … $$` 为独立公式，使用 KaTeX 渲染；`==高亮==` 和脚注也能正确预览。

### 通用功能

- **图片**：插入本机图片时会尽量使用相对于文档的路径。为了保护隐私，**不会加载网络图片**，本地图片可以正常显示。
- **自动保存**：编辑内容会自动保存，与“文本编辑”App 相同。可以通过“文件 → 恢复到 → 浏览所有版本”找回以前的版本。未命名的新文档会在第一次保存时询问保存位置。
- **语言**：窗口左下角可以选择文档语言（简体中文、繁体中文、日语、韩语）。同一个汉字在中文、日语、韩语里写法不同，选对语言，汉字才会按该语言的写法显示，导出的 PDF / HTML 也一样。默认“自动”：有假名按日语，有韩文按韩语，否则按系统语言选简体或繁体。手动选择的语言会按文件记住。
- **导出**：工具栏的“导出”按钮或“格式”菜单：
  - **导出 PDF**：A4 纸张、自动分页；
  - **导出 HTML**：生成一个独立的 HTML 文件，可以直接用浏览器打开。文档中的本地图片仍按相对路径引用，建议把 HTML 保存在与 .md 相同的文件夹中。

## 三、文件转换

点工具栏的“转换文件”按钮，或使用菜单“文件 → 转换文件为 Markdown…”（⇧⌘T），打开转换窗口。

1. **添加文件**：把文件或整个文件夹拖进窗口，或点“选择文件… / 选择文件夹…”。拖入文件夹时会包含所有子文件夹中支持的文件。
2. **选择模式**：
   - **快速**：使用 MarkItDown，速度快。适合 Word、Excel、PowerPoint、HTML、CSV 和文字型 PDF。
   - **高精度**：使用 Docling 进行版面分析、表格识别和 OCR 文字识别，适合论文、带表格或公式的 PDF、扫描版 PDF。**只对 PDF 生效**，其他格式仍按快速模式转换。
3. **Word 引擎**（可选）：选择“Pandoc（还原排版更好）”时，标题、列表、表格等排版还原得更好。两种引擎都会把 Word 里的图片导出到 `文件名_images` 文件夹，并在 Markdown 中用相对路径引用。
4. **OCR 引擎**（高精度模式）：两种引擎都不需要下载。
   - **RapidOCR（默认）**：PP-OCRv6 多语言模型，已内置在程序中。同一页中的简体中文、繁体中文、日文、英文等可以混合识别，不需要选择语言。
   - **Apple Vision**：系统“实况文本”所用的文字识别引擎，由 macOS 自带。它一次只能以一种东亚语言为主，所以选择它时需要再选“主要语言”（简体中文 / 繁体中文 / 日文，英文总是包含在内）。适合语言单一的文档；**中日文混合的文档请使用 RapidOCR**。
5. **识别数学公式**（高精度模式）：把公式转成 LaTeX，速度较慢，首次使用需要额外下载模型。
6. **输出位置**：
   - 默认保存到原文件所在的文件夹，文件名相同，扩展名为 `.md`；
   - 也可以选择“指定文件夹”。拖入文件夹时会保留子目录结构。
7. 点 **开始转换**。进度条显示整体进度，列表中每个文件会显示“成功 / 失败 / 已跳过”，失败时“说明”一栏会用中文写出原因。
8. 转换完成后，双击列表中的文件即可用编辑器打开生成的 Markdown；右键可以选择“在访达中显示”。

**同名文件**：如果要输出的 `.md` 已经存在，程序会先询问：覆盖、跳过、全部覆盖、全部跳过或取消。

**原始文件不会被修改**：程序只读取原文件，输出总是写入新的 `.md` 文件（以及图片文件夹）。

## 四、首次运行时会发生什么

- **快速模式和 Pandoc**：不联网，打开即可使用。
- **第一次使用高精度模式**时，程序会弹出窗口，列出需要下载的识别模型、每个模型的**下载来源**和**大小**，以及保存位置。只有点了“同意并下载”才会开始下载；点“取消”则什么都不会下载。
  - 需要下载的只有 Docling 的版面分析（约 172 MB）、表格识别（约 358 MB）以及可选的公式识别（约 640 MB）模型，来源是 Hugging Face 上 Docling 官方账号（`huggingface.co/docling-project`）；
  - OCR 不需要下载：Apple Vision 是 macOS 自带的，RapidOCR 的模型来自 PyPI 安装包，已经内置在程序中；
  - 模型保存在：`~/Library/Application Support/DropMD/models`
  - 下载使用 macOS 系统网络（与 Safari 相同的网络、DNS 和代理设置，支持 PAC 自动代理与 SOCKS 代理），只访问 huggingface.co 及其下载服务器，不保存 Cookie。每个文件下载后都会校验完整性；如果中途失败，重试时已完成的文件不会重复下载。
  - 下载完成后，以后的转换完全离线。也可以通过菜单“高精度模型”手动下载或打开模型文件夹。要删除模型，直接删除该文件夹即可。
- 第一次进行高精度转换时，加载模型需要一些时间（几十秒左右，取决于电脑性能），之后会快很多。

## 五、软件更新

菜单“DropMD → 检查更新…”打开“软件更新”窗口：

- 显示当前版本；点“立即检查”查看 GitHub 上是否有新版本及其更新说明。
- 有新版本时点“下载并更新”：DropMD 下载安装包并**校验完整性**，完成后点“重新启动”就换成新版本（有未保存的文档时会先问是否保存）。更新后，“下载”里以前的 DropMD 安装包会被移到废纸篓。如果 DropMD 不在“应用程序”等可以写入的位置，会改为打开安装包，按提示把 DropMD 拖到“应用程序”覆盖旧版本即可。
- **自动检查更新**：第一次启动时会询问是否开启。开启后每天最多检查一次，有新版本时提示您，由您决定是否下载；不会自动安装。
- **包括测试版（beta）**：勾选后也会提示测试版。当前为测试版时默认勾选。
- 检查更新只向 GitHub 查询版本号和更新说明，不会发送任何文件或个人信息。

## 六、隐私与安全

- 所有转换都在本机完成，不会把文件内容上传到任何服务器或在线 API。
- 转换引擎会在内部拦截一切对外的网络连接（只允许本机内部通信）。
- 联网行为只有两种，都需要您同意：下载高精度模式的识别模型；检查更新（向 GitHub 查询新版本）。都由 App 通过 macOS 系统网络完成。
- 没有数据收集、使用统计或广告；不会自动安装任何东西。
- 程序会记住您上次的设置（模式、输出位置等），只保存在本机。
- Markdown 预览页面设置了严格的内容安全策略：只能读取本机文件，禁止任何网络请求和文档中嵌入的脚本。
- 所用的开源组件及版本见“帮助 → 开源许可：第三方组件”和项目中的 `docs/依赖清单.md`。

## 八、已知限制

- **支持的格式**：`.docx`、`.xlsx`、`.pptx`、`.html/.htm`、`.pdf`、`.csv`。不支持旧版 Office 格式（`.doc`、`.xls`、`.ppt`），请先用 Office 另存为新格式。
- **加密或有密码的文件**无法转换。
- **快速模式**：PDF 只能提取文字，复杂排版、表格可能错乱；扫描版 PDF 无法提取文字（会提示改用高精度模式）。
- **高精度模式**：需要较多内存（建议 8 GB 以上），大文件可能需要几分钟；手写字、极度模糊的扫描件识别效果有限。
- **Liquid Glass 玻璃效果**需要 macOS 26 或更高版本；在 macOS 14～15 上程序同样可以使用，但界面会显示为普通的半透明材质。
- **Pandoc 引擎**只用于 Word（.docx）。
- **编辑器**：超大文件（数 MB 以上）的语法高亮和预览会变慢；预览不加载网络图片和网络字体。
- **单页**只保存 Markdown 能表示的格式：字体、字号、文字颜色、对齐方式等无法保存（所以工具栏中没有这些按钮）；从网页或 Word 粘贴的文字会保留粗体、斜体、链接等，其余格式在保存时去掉。
- 单页不支持的 Markdown 内容（例如一般的 HTML 代码、嵌套的折叠块）会以等宽文字显示，并**原样保存**，不会丢失。
- 单页中折叠块总是展开显示；公式以文字显示，渲染效果请在“双页”的预览或导出文件中查看。
- 程序体积较大（以实际构建为准），主要是高精度模式所需的 PyTorch 等组件。
- 程序没有 Apple 开发者签名，首次打开需要按上文手动允许。
- 不支持 Intel 芯片的 Mac（高精度模式依赖的 PyTorch 已不再提供 Intel Mac 版本）。
- 网络拦截作用于转换引擎的 Python 代码（包含所有转换库的 Python 部分）。Swift 界面只有模型下载和检查更新两处联网代码，都需要您同意。如需额外保障，可以用防火墙软件禁止 DropMD 联网（下载模型或更新时再临时允许）。
