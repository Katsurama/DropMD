## 完整清单

每次构建都会生成：

- `requirements-frozen.txt`：所有（包括间接）Python 库及其确切版本，打包在程序内部，也随 GitHub Actions 构建产物 `selftest-*` 一起上传；
- `THIRD_PARTY_LICENSES.md`：所有打包库的名称、版本、许可证和主页（由 pip-licenses 生成），打包在程序内部。

## 高精度模式的识别模型（不随程序打包，用户同意后下载）

| 模型 | 来源 | 固定版本（提交号） | 大小 |
|---|---|---|---|

大小于 2026-10-12 由 `tools/measure_model_sizes.py` 实测。下载由 Hugging Face 官方客户端完成，会校验文件完整性。各模型的许可证请以对应页面为准。

## 关于 Marker

需求中提到的 Marker 采用 GPL-3.0 许可，其模型权重另有商业使用限制，因此本项目选用许可更宽松、可完全离线运行的 Docling 作为高精度引擎。
