# DropMD 使用說明

DropMD 是一個 Mac 上的 **Markdown 編輯器**，同時可以把 Word、Excel、PowerPoint、HTML、PDF 等檔案轉換成 Markdown。所有操作都在您自己的 Mac 上完成，不會上傳任何檔案。

介面用 Swift / SwiftUI 原生開發，在 macOS 26 及以上採用 Liquid Glass 設計。

---

## 一、安裝

不需要安裝 Python，也不需要輸入任何指令。

### 系統需求

- Apple 晶片的 Mac（M1 / M2 / M3 / M4 …）
- macOS 14 或更新版本（macOS 26 及以上可顯示 Liquid Glass 玻璃效果）

### 安裝步驟

1. 按兩下 `DropMD-macOS-AppleSilicon.dmg`。
2. 在打開的安裝視窗中，依照箭頭提示，把 **DropMD** 圖像拖到右邊的「Applications」（應用程式）資料夾。
3. 第一次打開時，macOS 可能會提示「無法驗證開發者」，因為本程式沒有付費購買 Apple 開發者簽名。處理方法：
   - 打開「系統設定 → 隱私權與安全性」，在頁面下方找到關於 DropMD 的提示，按一下「強制打開」；
   - 或在 Finder 中按住 Control 鍵按一下 DropMD.app，選擇「打開」（較早的 macOS 版本有效）。
   這個操作只需要做一次。

## 二、編輯器

打開 DropMD 後，可以新增或打開 Markdown 檔案（選單「檔案 → 新增 / 打開」，或把 .md 檔案拖到 Dock 上的 DropMD 圖像上）。第一次打開 DropMD 時會詢問是否設為 Markdown 檔案的預設打開程式；設為預設後，在 Finder 中按兩下 .md 檔案就會用 DropMD 打開。之後可以在「DropMD → 設定…」（⌘,）中更改。不設為預設時，在 Finder 中按右鍵點 .md 檔案，選「打開檔案的應用程式 → DropMD」也可以。

介面語言預設跟隨 Mac 的系統語言（簡體中文、繁體中文、英文、日文）。想單獨幫 DropMD 換語言，在「DropMD → 設定…」的「介面語言」裡選，重新啟動 DropMD 後生效。

工具列最左邊的「單頁 / 雙頁」按鈕可以切換兩種顯示方式（也可以按 ⌘1 / ⌘2，或使用選單「顯示方式」）：

- **單頁**（預設，⌘1）：像 Pages / Word 一樣直接排版，**不需要會寫 Markdown**。看到的就是最終效果，儲存時自動轉換為標準的 Markdown 檔案。
- **雙頁**（⌘2）：左邊是 Markdown 原文，右邊是排版後的預覽。適合熟悉 Markdown 的使用者，或需要查看數學公式效果時使用。

兩種方式隨時可以切換，內容自動同步。右側的「格式」面板（工具列右邊的「格式」按鈕，或 ⌥⌘I）顯示游標處的段落樣式和文字樣式，按一下即可修改。插入表格、圖片、連結、摺疊區塊等在工具列中間；全部指令都在選單「格式」和「插入」中。

### 單頁怎麼用

- **段落樣式**：在「格式」面板中可以把段落設為正文、標題 1～6、引用或程式碼區塊（選單「格式 → 程式碼區塊」可選擇程式語言，包括 mermaid 流程圖）。快速鍵：⌥⌘1～⌥⌘6 為標題，⌥⌘0 為正文。
- **文字格式**：粗體（⌘B）、斜體（⌘I）、底線（⌘U）、刪除線（⇧⌘X）、**醒目提示**（⇧⌘H）、行內程式碼（⌥⌘C）、上標（⌃⌘=）、下標（⌃⌘-）、鍵盤按鍵樣式。選取文字後按按鈕即可，再按一次取消。沒有選取文字時，接下來輸入的文字會使用該格式。
- **清單**：項目符號、編號、**待辦清單**（按一下方框即可勾選）。在清單中按 Tab 增加縮排、⇧Tab 減少縮排；在空的清單項目上再按一次 Return 即結束清單。
- **插入**（工具列、「格式」面板或選單「插入」）：
  - **連結**（⌘K）、**圖片**（選擇本機圖片）、**表格**（在最後一格按 Tab 自動增加一列，按 Return 移到下一格）、**分隔線**；
  - **摺疊區塊**（⇧⌘D）：一個可以按一下展開 / 收起的區域，標題寫在 ▸ 後面，內容寫在下面帶直線的區域裡。按一下標題前的 ▸ / ▾ 收起或展開（只改變顯示，不改檔案；打開檔案時和瀏覽器一樣預設收起）。在標題上按 Return 進入內容；在內容的空白行上再按 Return 即離開摺疊區塊。輸出 HTML 或在 GitHub 上查看時可以按一下展開；
  - **提示框**：注意、提示、重要、警告、小心五種，第一行顯示提示框的名稱，下面寫內容。在「雙頁」預覽、GitHub 和 Obsidian 中顯示為帶顏色的方框；
  - **註腳**（⌥⌘F）：在游標處插入編號 [^1]，說明文字自動放到文件末尾；
  - **今天的日期**、**表情與符號**（系統的表情符號面板）；
  - **換行（不分段）**（⇧↩）：在同一段落內換行，儲存為 `<br>`；
  - **行內公式**（⌥⌘M）和 **公式區塊**（⇧⌥⌘M）：用 LaTeX 書寫，例如 `E=mc^2`。單頁中也直接顯示為數學符號，按兩下公式可以修改。
- **自動格式**：在段落開頭輸入 `- `、`1. `、`# `、`> `、`[] ` 後按空白鍵，會自動變成清單、編號、標題、引用、待辦。中文輸入法下的 `－ `、`1。 `、`＃ `、`》 `、`【】 ` 也可以。
- **貼上**：從網頁或 Word 貼上時保留粗體、斜體、連結等，顏色、字體等 Markdown 無法儲存的格式會自動去掉。
- **連結**：按住 ⌘ 按一下連結才會打開，一般按一下用於編輯文字。
- **頁邊距**：選單「顯示方式 → 頁邊距」或「DropMD → 設定…」裡選。「自動」時視窗越大，文字那一欄越寬；也可以固定選寬、標準、窄、最窄（文字填滿視窗）。

### 雙頁

- 左邊編輯 Markdown 原文，右邊即時預覽，捲動時兩邊自動對齊。
- **語法標示**：標題、粗體、斜體、程式碼、連結、清單、公式等用不同的顏色和字體顯示。
- **數學公式**：`$E=mc^2$` 為行內公式，`$$ … $$` 為獨立公式，使用 KaTeX 繪製；ChatGPT 等 AI 工具常用的 `\(E=mc^2\)` 和 `\[ … \]` 也能顯示；`==醒目提示==` 和註腳也能正確預覽。

### 通用功能

- **圖片**：插入本機圖片時會盡量使用相對於文件的路徑。為了保護隱私，**不會載入網路圖片**，本機圖片可以正常顯示。
- **自動儲存**：編輯內容會自動儲存，與「文字編輯」App 相同。可以透過「檔案 → 回復成 → 瀏覽所有版本」找回以前的版本。未命名的新文件會在第一次儲存時詢問儲存位置。
- **語言**：視窗左下角可以選擇文件語言（簡體中文、繁體中文、日語、韓語）。同一個漢字在中文、日語、韓語裡寫法不同，選對語言，漢字才會按該語言的寫法顯示，輸出的 PDF / HTML 也一樣。預設「自動」：有假名按日語，有韓文按韓語，否則按系統語言選簡體或繁體。手動選擇的語言會按檔案記住。
- **輸出**：工具列的「輸出」按鈕或「格式」選單：
  - **輸出 PDF**：A4 紙張、自動分頁；
  - **輸出 HTML**：產生一個獨立的 HTML 檔案，可以直接用瀏覽器打開。文件中的本機圖片會直接放進 HTML 檔案裡，儲存到哪個資料夾、傳給別人都能顯示；網路圖片仍按原位址引用（用瀏覽器打開時才會載入）。
- **快速查看**：在 Finder 裡選取 .md 檔案按空白鍵，就能看到排版後的效果（與雙頁的預覽相同），不用打開檔案。文中的本機圖片也會顯示：為此快速查看可以**唯讀**您的個人資料夾和外接硬碟裡的檔案（不能修改，也不連網）。

## 三、檔案轉換

按一下工具列的「轉換檔案」按鈕，或使用選單「檔案 → 轉換檔案為 Markdown…」（⇧⌘T），打開轉換視窗。

1. **加入檔案**：把檔案或整個資料夾拖進視窗，或按「選擇檔案… / 選擇資料夾…」。拖入資料夾時會包含所有子資料夾中支援的檔案。
2. **選擇模式**：
   - **快速**：使用 MarkItDown，速度快。適合 Word、Excel、PowerPoint、HTML、CSV 和文字型 PDF。
   - **高精度**：使用 Docling 進行版面分析、表格辨識和 OCR 文字辨識，適合論文、帶表格或公式的 PDF、掃描版 PDF。**只對 PDF 有效**，其他格式仍按快速模式轉換。
3. **Word 引擎**（可選）：選擇「Pandoc（還原排版更好）」時，標題、清單、表格等排版還原得更好。兩種引擎都會把 Word 裡的圖片輸出到 `檔名_images` 資料夾，並在 Markdown 中用相對路徑引用。
4. **OCR 引擎**（高精度模式）：前兩種不需要下載。
   - **RapidOCR（預設）**：PP-OCRv6 多語言模型，已內建在程式中。同一頁中的簡體中文、繁體中文、日文、英文等可以混合辨識，不需要選擇語言。辨識不出韓文和俄文，越南文會漏掉帶聲調的字母，這幾種語言請用 Xiaomi-OCR-0 試試（韓文和越南文也有錯字）。
   - **Apple Vision**：系統「原況文字」所用的文字辨識引擎，由 macOS 內建。它一次只能以一種東亞語言為主，所以選擇它時需要再選「主要語言」（簡體中文 / 繁體中文 / 日文，英文總是包含在內）。適合語言單一的文件；**中日文混合的文件請使用 RapidOCR**。
   - **Xiaomi-OCR-0**：Xiaomi（小米）開源的文件辨識模型（Apache-2.0，DropMD 與小米沒有關聯），文字更準，中日繁英和法德西俄混排都能辨識，公式和表格一起辨識（不需要再打開「辨識數學公式」）。第一次使用要下載約 1.8 GB。它比另外兩種慢：在 M4 晶片、16 GB 記憶體的 Mac 上，滿頁文字每頁約 20～30 秒，轉換時記憶體峰值約 5 GB（8 GB 記憶體的 Mac 沒有試過）。**不輸出 PDF 裡的圖片**，韓文和越南文錯字較多。
5. **辨識數學公式**（高精度模式）：把公式轉成 LaTeX，速度較慢，第一次使用需要額外下載模型。
6. **輸出位置**：
   - 預設儲存到原檔案所在的資料夾，檔名相同，副檔名為 `.md`；
   - 也可以選擇「指定資料夾」。拖入資料夾時會保留子資料夾結構。
7. 按 **開始轉換**。進度列顯示整體進度，清單中每個檔案會顯示「成功 / 失敗 / 已跳過」，失敗時「說明」一欄會寫出原因。
8. 轉換完成後，按兩下清單中的檔案即可用編輯器打開產生的 Markdown；按右鍵可以選擇「在 Finder 中顯示」。

**同名檔案**：如果要輸出的 `.md` 已經存在，程式會先詢問：覆蓋、跳過、全部覆蓋、全部跳過或取消。

**原始檔案不會被修改**：程式只讀取原檔案，輸出總是寫入新的 `.md` 檔案（以及圖片資料夾）。

## 四、第一次執行時會發生什麼

- **快速模式和 Pandoc**：不連網，打開即可使用。
- **第一次使用高精度模式**時，程式會跳出視窗，列出需要下載的辨識模型、每個模型的**下載來源**和**大小**，以及儲存位置。只有按了「同意並下載」才會開始下載；按「取消」則什麼都不會下載。
  - 需要下載的只有 Docling 的版面分析（約 172 MB）、表格辨識（約 358 MB）以及可選的公式辨識（約 640 MB）模型，來源是 Hugging Face 上 Docling 官方帳號（`huggingface.co/docling-project`）；
  - OCR 不需要下載：Apple Vision 是 macOS 內建的，RapidOCR 的模型來自 PyPI 安裝套件，已經內建在程式中；
  - 選擇 Xiaomi-OCR-0 時，只下載它自己的模型（約 1.8 GB），來源是 Hugging Face 上小米的官方帳號（`huggingface.co/xiaomi-research`），不需要 Docling 的模型；
  - 模型儲存在：`~/Library/Application Support/DropMD/models`
  - 下載使用 macOS 系統網路（與 Safari 相同的網路、DNS 和代理伺服器設定，支援 PAC 自動代理與 SOCKS 代理），只連到 huggingface.co 及其下載伺服器，不儲存 Cookie。每個檔案下載後都會驗證完整性；如果中途失敗，重試時已完成的檔案不會重複下載。
  - 下載完成後，之後的轉換完全離線。也可以透過選單「高精度辨識模型」手動下載或打開模型資料夾。要刪除模型，直接刪除該資料夾即可。
- 第一次進行高精度轉換時，載入模型需要一些時間（幾十秒左右，取決於電腦效能），之後會快很多。

## 五、軟體更新

選單「DropMD → 檢查更新…」打開「軟體更新」視窗：

- 顯示目前版本；按「立即檢查」查看 GitHub 上是否有新版本及其更新說明。
- 有新版本時按「下載並更新」：DropMD 下載安裝檔並**驗證完整性**，完成後按「重新啟動」就換成新版本（有未儲存的文件時會先問是否儲存）。更新後，「下載項目」裡以前的 DropMD 安裝檔會被移到垃圾桶。如果 DropMD 不在「應用程式」等可以寫入的位置，會改為打開安裝檔，依照提示把 DropMD 拖到「應用程式」覆蓋舊版本即可。
- **自動檢查更新**：第一次啟動時會詢問是否開啟。開啟後每次啟動時檢查一次，有新版本時提示您，由您決定是否下載；不會自動安裝。
- **包括測試版（beta）**：勾選後也會提示測試版。目前為測試版時預設勾選。
- 檢查更新只向 GitHub 查詢版本號和更新說明，不會傳送任何檔案或個人資訊。

## 六、隱私與安全

- 所有轉換都在本機完成，不會把檔案內容上傳到任何伺服器或線上 API。
- 轉換引擎會在內部攔截一切對外的網路連線（只允許本機內部通訊）。
- 連網行為只有兩種，都需要您同意：下載高精度模式的辨識模型；檢查更新（向 GitHub 查詢新版本）。都由 App 透過 macOS 系統網路完成。
- 沒有資料收集、使用統計或廣告；不會自動安裝任何東西。
- 程式會記住您上次的設定（模式、輸出位置等），只儲存在本機。
- Markdown 預覽頁面設定了嚴格的內容安全政策：只能讀取本機檔案，禁止任何網路請求和文件中嵌入的指令碼。
- 所用的開源元件及版本見「輔助說明 → 開源授權：第三方元件」和專案中的 `docs/依赖清单.md`。

## 八、已知限制

- **支援的格式**：`.docx`、`.xlsx`、`.pptx`、`.html/.htm`、`.pdf`、`.csv`。不支援舊版 Office 格式（`.doc`、`.xls`、`.ppt`），請先用 Office 另存為新格式。
- **加密或有密碼的檔案**無法轉換。
- **快速模式**：PDF 只能擷取文字，複雜排版、表格可能錯亂；掃描版 PDF 無法擷取文字（會提示改用高精度模式）。
- **高精度模式**：需要較多記憶體（建議 8 GB 以上），大檔案可能需要幾分鐘；手寫字、非常模糊的掃描檔辨識效果有限。
- **Liquid Glass 玻璃效果**需要 macOS 26 或更新版本；在 macOS 14～15 上程式同樣可以使用，但介面會顯示為一般的半透明材質。
- **Pandoc 引擎**只用於 Word（.docx）。
- **編輯器**：超大檔案（數 MB 以上）的語法標示和預覽會變慢；預覽不載入網路圖片和網路字體。
- **單頁**只儲存 Markdown 能表示的格式：字體、字級、文字顏色、對齊方式等無法儲存（所以工具列中沒有這些按鈕）；從網頁或 Word 貼上的文字會保留粗體、斜體、連結等，其餘格式在儲存時去掉。
- 單頁不支援的 Markdown 內容（例如一般的 HTML 程式碼、巢狀的摺疊區塊、檔案開頭的 YAML 資訊、參照式連結的位址、清單項目裡的續段、引用裡的清單）會以等寬文字顯示，並**原樣儲存**，不會遺失。清單項目下面只跟程式碼區塊時（AI 工具常這樣寫安裝步驟），單頁裡可以直接編輯。
- 在單頁裡修改後儲存，沒改過的段落保持原樣；改過的段落，有些寫法會換成意思相同的標準寫法：行尾兩個空格或反斜線的換行存為 `<br>`，縮排 4 格的程式碼存為 ``` 程式碼區塊，`===` 底線式標題存為 `#` 標題，`*` 清單存為 `-` 清單，引用裡不帶 `>` 的續行補上 `>` 等。
- 程式檔案較大（以實際建置為準），主要是高精度模式所需的 PyTorch 等元件。
- 程式沒有 Apple 開發者簽名，第一次打開需要依照上文手動允許。
