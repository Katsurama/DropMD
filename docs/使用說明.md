# 👋 歡迎使用 DropMD

DropMD 是一個 Mac 上的 Markdown 編輯器：**像 Word 一樣直接排版**，儲存下來就是標準的 Markdown 檔案。它還能把 Word、Excel、PowerPoint、PDF 等檔案轉換成 Markdown。

> [!TIP]
> 這份說明本身就是一個 Markdown 文件，你可以隨意在上面點點、改改，試試各種功能。不用擔心改壞：每次從選單「輔助說明 → 使用說明」打開的都是一份新的。

## 🚀 3 步上手

- [ ] 選單「檔案 → 新增」（⌘N），新增一個文件
- [ ] 在第一行輸入 `# ` 再打字，它就變成了大標題；換行後直接寫正文
- [ ] 選取幾個字，按 ⌘B 加粗。寫完關閉視窗時選個位置儲存，就得到一個 `.md` 檔案

> [!NOTE]
> 不需要會寫 Markdown。看到的就是最終效果，格式會在儲存時自動寫成 Markdown。

## ✍️ 寫文件

### 單頁和雙頁

工具列最左邊可以切換兩種顯示方式：

| 方式 | 快速鍵 | 適合 |
| --- | --- | --- |
| **單頁** | ⌘1 | 像 Word、Pages 一樣直接排版，看到的就是效果 |
| **雙頁** | ⌘2 | 左邊 Markdown 原文，右邊單頁；兩邊都能改，內容和捲動即時同步 |

在雙頁的左邊移動游標時，右邊會標出對應的位置。不想要可以在「DropMD → 設定⋯ → 一般」裡關掉，或換一種標記樣式（邊框、側邊線、游標）。中間的分隔線可以拖移，按兩下回到一半一半。

### 打字時自動變格式

在一段的開頭輸入下面這些符號，再按空白鍵：

| 輸入 | 變成 |
| --- | --- |
| `# ` `## ` `### ` | 標題 1、2、3 |
| `- ` 或 `* ` | 項目符號清單 |
| `1. ` | 編號清單 |
| `[] ` | 待辦清單（點按方框就能勾選） |
| `> ` | 引言 |

> [!TIP]
> 中文輸入法下的 `－`、`1。`、`＃`、`》`、`【】` 也可以，不用切換到英文。

### 常用快速鍵

| 操作 | 快速鍵 |
| --- | --- |
| 粗體 / 斜體 / 底線 | ⌘B / ⌘I / ⌘U |
| 刪除線 / 醒目標示 | ⇧⌘X / ⇧⌘H |
| 行內程式碼 | ⌥⌘C |
| 標題 1～6 / 正文 | ⌥⌘1～⌥⌘6 / ⌥⌘0 |
| 連結 / 圖片 | ⌘K / ⇧⌘K |
| 表格 | ⌥⌘T |
| 增加 / 減少縮排 | Tab / ⇧Tab（在清單裡） |
| 同一段裡換行 | ⇧↩ |
| 顯示「格式」面板 | ⌥⌘I |

所有指令都能在選單「格式」和「插入」裡找到。右邊的「格式」面板會顯示游標處的樣式，點按一下就能改。

### 右鍵選單

在不同的內容上按右鍵，會出現對應的常用操作：

- **表格**：插入列或欄、刪除列或欄、對齊方式、拷貝表格、刪除表格
- **連結**：打開、編輯、拷貝、移除
- **圖片**：編輯替代文字、在 Finder 中顯示、刪除
- **程式碼區塊**：拷貝程式碼、選擇語言
- **提示框**：換類型、轉換為引言
- **選取的文字**：刪除線、醒目標示、行內程式碼、清除格式

## 📦 插入各種內容

點按工具列中間的按鈕，或使用選單「插入」。

### 表格

- 按 Tab 或 Return 移到下一格；在最後一格按 Tab 自動加一列，按 Return 跳到表格下面
- 拖移兩欄中間的線可以調整欄寬
- 選取整列按 Delete 刪除這幾列；在表格下面一段的開頭按兩下 Delete，刪除整張表格（第一下先選取，防止誤刪）

### 提示框

就是你現在看到的這種帶顏色的方框，有「注意、提示、重要、警告、小心」五種：

> [!IMPORTANT]
> 提示框在 GitHub 和 Obsidian 裡也會顯示成帶顏色的方框。

### 程式碼區塊

把段落設為程式碼區塊後，可以在右鍵選單裡選程式語言。滑鼠移到程式碼區塊上，右上角會出現「拷貝」按鈕：

```swift
print("Hello, DropMD!")
```

### 摺疊區塊

<details>
<summary>點按這裡展開看看</summary>

摺疊區塊可以把一段內容收起來，點按標題前的三角形展開或收起。插入摺疊區塊的快速鍵是 ⇧⌘D。

</details>

### 公式、註腳和其他

- **公式**：行內公式 ⌥⌘M，公式區塊 ⇧⌥⌘M，用 LaTeX 書寫，例如 $E=mc^2$。按兩下公式可以修改
- **註腳**：⌥⌘F 在游標處插入編號，說明文字自動放到文件末尾
- **圖片**：插入本機圖片時會盡量用相對於文件的路徑。為了保護隱私，**不會載入線上圖片**
- **今天的日期**、**表情與符號**：在選單「插入」裡

## 🔗 連結

點按連結時，預設先詢問再打開，免得想改連結文字時誤打開。可以在「DropMD → 設定⋯ → 一般 → 點按連結時」改成「直接打開」或「按住 ⌘ 點按才打開」。按住 ⌘ 點按總是直接打開。

連結到另一個 `.md` 檔案時，會用 DropMD 打開它；連結到其他檔案時，會在 Finder 中顯示。

## 📤 儲存、輸出和分享

- **自動儲存**：和「文字編輯」一樣自動儲存。想找回以前的內容，用選單「檔案 → 回復成 → 瀏覽所有版本」
- **輸出**：工具列的「輸出」按鈕，可以輸出 **PDF**（A4 紙張）或 **HTML**（文件裡的本機圖片會直接放進 HTML 檔案，傳給別人也能顯示）
- **分享**：工具列的「分享」按鈕，透過 AirDrop、郵件、訊息等把這個 `.md` 檔案傳出去
- **快速查看**：在 Finder 裡選取 `.md` 檔案按空白鍵，不用打開就能看到排版後的效果

> [!TIP]
> 視窗左下角可以選擇文件語言（簡體中文、繁體中文、日文、韓文）。同一個漢字在中文、日文、韓文裡寫法不同，選對語言，漢字才會按該語言的寫法顯示。

## 🔄 把檔案轉換成 Markdown

選單「檔案 → 轉換檔案為 Markdown⋯」（⇧⌘T）打開轉換視窗：

1. 把檔案或整個資料夾拖進視窗，也可以點按「選擇檔案⋯」
2. 選擇模式：
   - **快速**：適合 Word、Excel、PowerPoint、HTML、CSV 和文字型 PDF
   - **高精度**：適合論文、掃描版 PDF、帶表格或公式的 PDF（只對 PDF 生效）
3. 點按「開始轉換」。完成後，按兩下清單裡的檔案就能用 DropMD 打開

轉換好的 `.md` 預設放在原檔案旁邊，Word 裡的圖片會輸出到「檔名_images」資料夾。**原檔案不會被修改。**

> [!NOTE]
> 第一次用高精度模式時，需要下載辨識模型（約 530 MB，勾選「辨識數學公式」時再加約 640 MB）。下載前會列出來源和大小，你同意後才會下載；下載一次之後就能離線使用。

| OCR 引擎（高精度模式） | 特點 |
| --- | --- |
| **RapidOCR**（預設） | 同一頁裡的簡體、繁體、日文、英文可以混在一起辨識 |
| **Apple Vision** | macOS 內建，適合只有一種語言的文件，需要選擇主要語言 |
| **Xiaomi-OCR-0** | 更準，公式和表格一起辨識；第一次要下載約 1.8 GB，速度較慢 |

## ⚙️ 設定

選單「DropMD → 設定⋯」（⌘,）分為四頁：

| 頁面 | 可以做什麼 |
| --- | --- |
| **一般** | 外觀（淺色 / 深色）、頁邊距、點按連結時、雙頁的位置標記、介面語言、設為 `.md` 的預設打開程式 |
| **更新** | 檢查新版本、啟動時自動檢查、包括測試版 |
| **贊助** | 喜歡 DropMD 的話，可以請作者喝杯咖啡 |
| **關於** | 版本號、GitHub 儲存庫、回報問題、交流群、開源授權 |

> [!TIP]
> 新版本會先發布測試版。想搶先用新功能，就在「更新」頁勾選「包括測試版（beta）」。

## 🔒 隱私

- 所有編輯和轉換都在你自己的 Mac 上完成，不會上傳任何檔案
- 只有兩件事會連網，而且都要你同意：下載高精度模式的辨識模型、檢查更新
- 沒有資料收集、使用統計或廣告，不會自動安裝任何東西

## ❓ 常見問題

<details>
<summary>儲存後，有些格式不見了？</summary>

Markdown 只能儲存粗體、斜體、標題、清單、表格這類格式。字體、字級、文字顏色、對齊方式等無法儲存，所以工具列裡也沒有這些按鈕。從網頁或 Word 貼上時，粗體、斜體、連結會保留，其他格式會去掉。

</details>

<details>
<summary>文件裡有些內容顯示成等寬文字？</summary>

單頁暫時不支援的寫法（例如一般的 HTML 程式碼、檔案開頭的 YAML 資訊）會這樣顯示，並原樣儲存，不會遺失。切到雙頁就能在左邊直接修改。

</details>

<details>
<summary>哪些檔案可以轉換？</summary>

`.docx`、`.xlsx`、`.pptx`、`.html`、`.pdf`、`.csv`。舊版 Office 格式（`.doc`、`.xls`、`.ppt`）請先用 Office 另存為新格式；加密或有密碼的檔案無法轉換。

</details>

<details>
<summary>遇到問題去哪裡回報？</summary>

選單「輔助說明 → 回報問題⋯」會打開 GitHub 的問題頁面。也可以在「輔助說明」選單裡加入 QQ 交流群或 Discord 社群。

</details>
